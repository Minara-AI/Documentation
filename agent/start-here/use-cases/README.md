# Use Cases

These use cases show Minara Harness through tested Minara Desktop workflows. They are grounded in Minara Desktop 1.0.2 screenshots captured on September 11, 2026.

The screenshots are examples, not current market data. Account balances, wallet identifiers, and private activity were cropped or redacted before inclusion.

## Boundaries

These workflows do not turn research into permission. Copilot output is not a validated predictive signal. Backtest rankings are not verified live performance. Portfolio views only cover connected Minara accounts. Computer control is explicit and permissioned; it is not passive screen awareness.
